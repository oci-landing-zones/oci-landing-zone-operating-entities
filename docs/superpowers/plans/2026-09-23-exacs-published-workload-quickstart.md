# Published ExaDB-D Workload UC1 Quickstart Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Publish a complete UC1 Cloud Exadata Database workload quickstart for both ExaCS foundation paths, with generated JSON snapshots and OKE-pattern documentation.

**Architecture:** Extend the existing ExaCS published-profile family with a UC1 regular Exadata Database Service workload definition, then render its three same-root operation documents through a publication-only adapter. Thin entrypoints materialize identical logical workload surfaces under single-stack and multi-stack; documentation supplies their distinct foundation handoffs and ordered state lifecycle.

**Tech Stack:** Jsonnet, existing bash gen/generate.sh publication pipeline, Python unittest fixture runner, JSON, Markdown.

## Global Constraints

- Keep gen/workload-extensions/exacs/exacs_database_workload.libsonnet as the Cloud Exadata operation source of truth.
- Use a published UC1 profile; committed JSON snapshots must be generated by bash gen/generate.sh, never edited manually.
- Publish regular Exadata Database Service on Dedicated Infrastructure only: Cloud Exadata Infrastructure, Cloud VM Cluster, DB Home, CDB, and PDB.
- Keep the workload in three ordered Orchestrator states. Do not combine the three cloud_exadata_database_configuration documents into one operation.
- Keep the workflow customer-template-only: explicit Vault secret OCID and SSH public-key replacements are mandatory before planning.
- Support both existing ExaCS single-stack and multi-stack foundation paths without mixing their foundation artifacts into workload configurations.
- Preserve Blueprint Factory as the customization path; do not change config-mode output names or generic ExaCS placement validation.
- Do not run Terraform, Resource Manager plans, or OCI deployments as part of this repository change.
